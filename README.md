## 📌 Visão Geral
Este projeto consiste num **pipeline automatizado em Python** para consumo, coleta e estruturação de dados climáticos em tempo real através da integração com uma API REST pública (ex: OpenWeatherMap).

O objetivo principal é demonstrar a extração de dados não estruturados (JSON), o tratamento de variáveis meteorológicas e a conversão dessas informações em dataframes estruturados e prontos para consumo por ferramentas de Business Intelligence (Power BI) ou análises exploratórias em SQL/Python.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
- **Linguagem:** Python 3.x
- **Requisições HTTP:** `requests`
- **Tratamento e Estruturação:** `pandas`
- **Formato de Payload:** JSON
- **Ambiente:** VS Code / Jupyter Notebook
